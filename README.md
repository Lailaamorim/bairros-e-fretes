# 🚚 Bairros & Fretes

> 📚 Consulta rápida e prática de valores de frete por bairro  
> 🚀 Facilitando a rotina e a agilidade nas vendas no dia a dia

Este repositório é dedicado ao projeto **Bairros & Fretes**, uma aplicação web desenvolvida para ajudar vendedores a encontrarem rapidamente o valor do frete para cada localidade sem complicações.

---

## 🎯 Objetivo

Facilitar e agilizar o atendimento de vendas através de uma ferramenta simples de consulta, oferecendo recursos como:

- 🔍 **Busca Dinâmica:** Pesquisa instantânea por nome do bairro.
- 💰 **Exibição Clara:** Visualização direta do valor do frete ou indicação de locais não atendidos.
- ✏️ **Gerenciamento de Dados:** Possibilidade de adicionar, editar ou remover bairros e preços diretamente na interface.
- 💾 **Persistência Local:** Salvamento dos dados no navegador via `localStorage`.

---

## 🚚 Sobre o Projeto

O **Bairros & Fretes** foi criado com o intuito de resolver uma dor comum na rotina comercial: a perda de tempo procurando taxas de entrega em tabelas extensas.

Com a aplicação, basta digitar parte do nome do bairro na barra de busca para obter o valor exato na hora, tornando a resposta ao cliente muito mais rápida e eficiente.

---

## 🚀 Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as tecnologias fundamentais da web:

- 🌐 **HTML5:** Estruturação semântica de toda a página.
- 🎨 **CSS3:** Estilização moderna, responsiva e agradável.
- ⚡ **JavaScript (ES6+):** Lógica de busca, manipulação do DOM e gerenciamento dos dados no `localStorage`.
